# Namma-Shaale Inventory

Namma-Shaale Inventory is an Android application developed for efficient school asset and inventory management. The application helps schools manage assets, monitor repair requests, track inventory conditions, and generate reports through a simple and user-friendly mobile interface.

## Problem Statement

Managing school inventory manually can be difficult, time-consuming, and error-prone. Schools often face challenges in tracking assets, monitoring damaged items, maintaining repair records, and generating inventory reports efficiently.

Namma-Shaale Inventory solves this problem by providing a digital Android-based inventory management system with dashboard analytics, asset tracking, search functionality, repair monitoring, and report generation.

---

## Features

- Dashboard Analytics
  - Total Assets
  - Healthy Assets
  - Repair Needed Assets
  - Broken Assets

- Asset Registration and Management
- Asset Condition Tracking
- Repair Request Monitoring
- Inventory Search and Filter Functionality
- Image Upload and Asset Documentation
- Report Generation and Export
- Admin and Staff Mode Toggle
- Offline Data Storage using Room Database
- Modern Dark-Themed UI/UX

## Installation Steps

1. Clone the repository

```bash
git clone https://github.com/srajannpoojari/Namma-Shaale-Inventory.git
```

2. Open the project in Android Studio

3. Sync Gradle files

4. Run the application using an Android Emulator or physical Android device

---

## How to Run

- Open Android Studio
- Select Emulator or Connected Device
- Click Run ▶ button
- The application will build and launch automatically
